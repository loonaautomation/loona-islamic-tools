よくある質問

タスビーフカウンターはどのように動作しますか？

詠唱ごとに大きなカウントエリアをタップ（またはスペースバーを押して）してください。カウンターは現在のラウンドをあなたの目標 — 33、99、100、またはあなた自身の数 — に対して記録し、その後自動的に新しいラウンドを開始して、ラウンド数と生涯合計に加算します。

目標に達すると振動しますか？

振動に対応したスマートフォンでは、カウンターはラウンドを完了したときに短く振動します。そのため、目を閉じたまま、またはスマートフォンをポケットに入れたままでも数えることができます。

私の合計は保存されますか？

はい — ラウンドと生涯の合計は、このデバイス上のあなたのブラウザにのみ保存されます。アップロードされるものは何もありません。ブラウザデータを消去するとリセットされます。

どのズィクルを数えることができますか？

プリセットには SubhanAllah、Alhamdulillah、Allahu Akbar、La ilaha illallah、Astaghfirullah、Salawat（durud）が含まれています。独自のカスタムのズィクルや言葉を入力することもできます。

使い方

カウンターは数珠のデジタル版です。リストからズィクルを選んでください — SubhanAllah、Alhamdulillah、Allahu Akbar、La ilaha illallah、Astaghfirullah、Salawat — または自分の好きなフレーズを入力し、目標を選んでください：33、99、100、または 100,000 までの任意の数。大きなボタンをタップするごとに一つ加算されます。カウントが目標に達すると、電話が振動し（バイブレーション対応デバイスで）、ラウンドが完了し、カウントは次のラウンドへそのまま続きます。ラウンド数と通算合計は、このデバイスのこのブラウザにのみ保存されます。

実際の例

目標 33 で SubhanAllah を選び、33 回タップしてください：電話が短く振動し、ラウンドカウンターが 1 に進み、合計が 33 増えます。あと二回繰り返すと、おなじみの 99 — 三ラウンド丸ごと — になり、ページを閉じて戻ってきても合計は明日もそこにあります。

よくある質問

33、99、100 以外の目標を設定できますか？

はい — カスタム目標フィールドは 1 から 100,000 までの任意の数を受け付けます。これは、標準の数珠の目標では小さすぎる、500 の istighfar や 1,000 の salawat のような固定の毎日の wird に適しています。

生涯の合計は、ズィクルごとに別々に保持されますか？

いいえ — ページには共有の累計が一つとラウンドカウンターが一つだけあり、どのズィクルを数えていても同じです。SubhanAllah から Astaghfirullah に切り替えてもリセットされません。このデバイスで数えたすべての合計になります。

私の iPhone は目標に達しても振動しません — 何か壊れていますか？

いいえ。振動は Vibration API を使いますが、iPhone はウェブページにこれを提供していません。そのため、iPhone では完了したラウンドは画面にのみ表示されます。ほとんどの Android スマートフォンでは、スマートフォン自体の設定で振動がオンになっていれば、振動は動作します。

ブラウザデータを消去したりスマートフォンを変えたりすると、私の合計はどうなりますか？

それらはゼロから再び始まります。ラウンドと合計は、このデバイス上のこのブラウザのストレージにのみ存在します — オンラインに保持されるものはなく、アカウントに結び付けられることもありません — そのため、サイトデータを消去したり、新しいスマートフォンに移動したりすると、新しいカウントが始まります。

カウンターは目標を超えても数え続けますか？

はい。目標ではバイブレーションがあり、ラウンドカウンターが一つ上がり、カウントは自動的にゼロから再開します — そのため、何も押したり位置を見失ったりすることなく、66、99、その先まで続けられます。
